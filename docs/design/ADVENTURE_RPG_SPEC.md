# 日語冒險 RPG：P2 設計與實作契約

版本 0.1｜2026-10-16｜需求來源：[project.md §2.3、§3.3、§4](../../project.md)｜執行清單：[tasks.md](../../tasks.md)

## 1. 決策範圍與證據

使用者已選擇第二張「日語旅行手帳」的原創插畫、平板為主、自由移動的地圖、道館挑戰、金幣與角色／夥伴裝備；道館明確選擇「戰鬥為主：運用日語答題，讓角色或夥伴出招」。2026-10-16 看過探索、商店、戰鬥概念後回覆：「看起來不錯，我們以這種方式推進project」。這是產品與美術方向的確認。

本文件將方向落成可實作的預設契約。§5、§6 的數值是 agent 提出的 **原型參數**，尚未經可玩性與兒童試用驗證，不宣稱使用者逐項核准。原型可先依此實作；調整需在 P2-10 的決策紀錄列版本、原因、測試及影響，不能隱藏在程式常數中。數值本身只在本文件維護。

概念圖見 [圖稿與來源](concepts/README.md)。圖內文字、價格、血量、人物與物種均為示意，沒有實作或裝置驗收效力。正式規則以本文件及 project.md 為準；衝突時先同步文件。此次方向確認不取代 P0／P1 gate、教材人工審核或實體平板測試。

## 2. P2 的有界範圍

| 交付 | 明確範圍 |
|---|---|
| 世界 | 一座可自由行走的小鎮；家門出入口、道館、裝備店三個可達目的地；兩名有對話的居民。P2 不製作多城鎮、隨機野戰或建島。 |
| 場景 | 一張室外地圖；道館大廳／教學與戰鬥場景；商店試穿場景。家門可開休息／續玩面板，不增加完整住宅系統。 |
| 角色 | 一名玩家角色、一隻跟隨夥伴、一名道館導師、一種對手；兩名居民可共用基礎骨架但須可辨識。 |
| 裝備 | 三件可購買物：角色帽子、角色背包、夥伴圍巾。地圖、試穿、戰鬥使用一致造型；每個欄位可卸下。 |
| 學習 | 正式 U01；詞彙、文法、閱讀、聽力及原有完整內容配額。教學、練習戰、獨立檢核與延後複習分開記錄。 |
| 挑戰 | 一套可重玩的道館戰鬥；普通攻擊、防守、夥伴技三種行動；支援勝利、失敗、撤退、中斷恢復。 |
| 成果 | 金幣帳本、背包、裝備、位置、對話旗標、戰鬥及學習存檔；兩玩家隔離；家長學習摘要。 |

使用現有夥伴 ID 之一重製主示範美術；其他既有夥伴資料保留並提供相容顯示，不轉成新種、不重置成長。圖稿中的狐狸只是造型探索；P2-11 記錄實際採用的既有 ID 與對照。新種類、捕捉、繁殖、隨機掉寶、付費貨幣均不在 P2。

## 3. 探索與互動

- 選擇玩家後「繼續冒險」回最後安全位置；有未完戰鬥時先提供「繼續挑戰／返回道館」，不把另一玩家的 session 帶進來。
- 主要操作為點地面尋路；可切換固定四方向控制。鍵盤方向鍵／WASD 移動，Enter／Space 互動，Esc 暫停。輸入焦點在文字欄位時不攔截移動鍵。
- 路徑必須沿可通行區域；建築、河流、樹與圍牆具碰撞。不可達位置顯示短暫落點提示並留在最近可達位置，不穿牆、不永久走路。
- 只在互動範圍內出現「交談／進入道館／進入商店」。入口觸發後鎖定至場景切換結束，避免連點重入；門口不放裝飾遮擋玩家。
- 背景失焦、pointercancel、觸控中斷、開面板及玩家切換都停止移動。避免捲動頁面與方向控制搶手勢；不能全頁停用縮放。
- 手帳提供等價的地點清單，可用鍵盤或點選直接前往已可達地點；相同先修與存檔規則，不要求精準拖曳或走位才能學習。
- 對話可重讀、退出、朗讀；一次只顯示一段，下一段由孩子觸發。居民可給故事線索與 U01 練習，裝飾對話不自動計為 Attempt。
- 首次引導只展示移動、靠近互動、手帳三件事，可跳過／重播。沒有每日待辦強制遮罩、連續登入懲罰或必須先清完任務才能逛街的規則。

## 4. 道館與課程如何接合

1. 道館大廳提供「認識新內容」「練習對戰」「檢查學會了嗎」「回到小鎮」。先修不足時提供明確教學入口，仍可離開探索。
2. 教學引用 U01 正式內容 ID；未教內容不能靠隨機題池突然加入戰鬥。首次作答、提示、錯誤、跳過、重試延用 project.md §5。
3. 練習戰使用共同播放器的四種 renderer；選招不選題型，不能靠只使用簡單招式繞過必學能力。選題由 learning 層依教學進度、到期複習、技能與題族決定。
4. 一般戰鬥不倒數；題目音訊未成功播放不允許以播放失敗判錯。提示不消耗金幣；提示後答對可以在練習戰出招，但不計為獨立答對。
5. 戰鬥依血量／回合上限結束；學習小節仍每五個有效作答累積，可跨戰鬥續接。提前勝利不跳過剩餘學習項目、不補虛構答案；未滿五題顯示部分進度。題庫不足明示縮短，不複製同題湊數。
6. 每日建議小節數留在手帳／家長計畫，作為建議而非冒險門票。到期複習以導師邀請呈現，沒有到期題時仍可自由練習或探索。
7. 獨立檢核使用固定測量規則，不受裝備與戰鬥傷害影響；戰鬥勝利不等於能力節點通過。P5 正式模擬保留考試介面，不套戰鬥、道具提示或裝備加分。

## 5. 回合狀態與原型參數

狀態依序：選招 → 題目 → 提交中 → 解說／回饋 → 孩子按「繼續戰鬥」 → 招式與敵方行動 → 下一回合或結果。全程可暫停；儲存錯誤保留待提交內容且不可結算血量。

選招後鎖定當回合題目與 questionInstanceId；切換、重整、暫停不重新抽題。第一次有效提交以 `(profileId, battleId, turnId)` 同交易保存 Attempt 引用、行動、雙方血量、技能次數與下一狀態；重播動畫不重算傷害。回饋已保存但尚未看完時，恢復回饋畫面。

原型設定 `battle-rules-v0.1`：

| 參數／行動 | 規則 |
|---|---|
| 開場 | 玩家 HP 40；對手 HP 30；第 1 回合開始。每場重設 HP 與夥伴技次數。 |
| 普通攻擊 | 當回合首次提交答對造成 8 傷害；答錯或跳過為 0。 |
| 防守 | 答對造成 4 傷害，否則為 0；無論答案，本回合敵方基礎傷害減半。此遊戲效果不改變正誤判定。 |
| 夥伴技 | 每場可用一次；首次提交時消耗，答對造成 12 傷害，否則為 0。送出前取消選招不消耗。 |
| 敵方 | 每第三回合基礎傷害 8，其餘 4；選招前明示下一招為普通或強攻。對手 HP 已歸零時不再攻擊。 |
| 裝備減傷 | 在防守減半後再扣裝備減傷，最終至少 1；上限見 §6。 |
| 勝負 | 對手 HP 歸零勝利；否則玩家 HP 歸零或第 8 回合仍未勝利則結束挑戰。先判對手 HP，再判玩家 HP，最後判回合上限。 |
| 錯題 | 回饋顯示正解與原因；看完後進下一回合。立即重看不再次出招、發幣或新增獨立證據；補救依 project.md §5.4 間隔安排。 |
| 退出 | 撤退與失敗均回道館，不沒收既有金幣／裝備，保留已提交學習與結束原因；未提交題不計錯。 |

P2-14 至少驗證全對、全錯、交錯錯誤、提示、跳過、技能耗盡、強攻前防守、最大減傷、勝負邊界與八回合上限。P2-09 的可玩性檢查需比較策略是否有可觀察差異及操作負擔；通過數學測試不能宣稱孩子覺得好玩，後者在 P3 實測。

## 6. 金幣、購買與裝備原型

原型設定 `economy-v0.1`：初始餘額 0；同道館挑戰首勝 60 金幣，後續每個新完成且獲勝的有效 battleId 為 10；失敗、撤退為 0。首勝鍵固定為 `(profileId, challengeId)`，題目或美術改版不重置首勝。refresh／重送同 battleId 不算重玩。沒有真實金流、每日連登獎勵、抽獎或付費提示。

| 物品 ID | 穿戴對象／欄位 | 價格 | 原型效果 |
|---|---|---:|---|
| gear-travel-hat | 角色／head | 40 | 外觀；減傷 1 |
| gear-companion-scarf | 夥伴／neck | 60 | 外觀；減傷 1 |
| gear-travel-pack | 角色／back | 80 | 外觀；減傷 1 |

總減傷最多 2，不增加能力分數或自動答題。每個物品只能擁有一件；同欄位只能穿一件。P2 不實作販售、交換、消耗品或貨幣轉移。這些值用於驗證購物循環；P3 觀察是否誘發無意義重刷，再依版本調整。

商店狀態必備：可購買、試穿、已擁有、已裝備、餘額不足、提交中、購買失敗、商品版本不符。試穿只改預覽，離開復原；已擁有物品提供「裝備／卸下」，不能再次扣款。購買前可見價格與效果，主要操作為「購買並裝備」。

交易在資料層驗證玩家、商品 ID／catalogVersion、價格、餘額、持有狀態與欄位；同一 purchaseId 的扣款、所有權、穿戴及 receipt 全部成功或全部回復。兩分頁買同物只扣一次；不同物件競爭同餘額不允許負數。UI 不直接寫餘額，不能信任 URL 或畫面傳入的價格。

## 7. UI／UX 與美術實作守則

完整 tokens、字級與目標尺寸見 project.md §4，不另維護第二套數值。

- 平板橫向是主要構圖；地圖顯示連續空間，手帳／背包／互動鍵位於安全邊界。鏡頭跟隨有邊界，人物不躲在固定 HUD 後面。
- 戰鬥畫面上方約四成放角色與戰況，下方優先給可閱讀題目。長閱讀與排序可收合場景，不能為維持示意圖比例縮小字。手機改成單欄，直向與文字放大都可完成。
- 商店平板左邊選物、右邊完整試穿；手機先商品後預覽與操作，焦點與 DOM 順序一致。不能只換背包數字而沒有角色穿戴變化。
- 美術採第二張的墨線、水彩、暖紙、深藍與少量陶土色。場景、角色、物件同一套線條與透視；路面、障礙、門口、玩家有足夠辨識差異。
- P2-11 交付角色／夥伴四方向 idle／walk、裝備定位與遮擋順序、戰鬥 idle／action／feedback、建築入口與地形層、三件道具圖及 manifest。允許以少量精修動畫幀起步，但全部狀態須可辨識且減少動態模式可用。
- 概念圖不能整張當可操作介面：地圖需要可通行區、碰撞、入口與角色層；按鈕、招牌互動標籤、中文、日文、ruby 均用可縮放真文字與 DOM。功能圖示可用一致 SVG；教材與角色不以 emoji／雜牌 icon 代替。
- 素材 manifest 記錄 ID、版本、來源、生成／修訂方式、權利檢查、尺寸、透明區、檔案大小與使用位置。建立角色設定表，核對跨場景造型；不直接複製參考遊戲的角色、地圖或標誌。
- 提示、答錯、受擊不羞辱孩子；無流血或殘酷畫面。不閃爍催促，不讓夥伴因離線或沒完成計畫受苦。
- 新場景冷載入、移動與面板開啟在實體平板記錄耗時與卡頓；動畫循環暫停／離場停止。載入中有清楚回饋，不用大張未壓縮概念 PNG 當 runtime 資產。

## 8. 資料、版本與離線

新增資料至少包含 `profileId` 與資料版本：WorldCheckpoint（mapId、safePosition、facing、storyFlags、worldVersion）；BattleSession（challengeId、turnId、questionInstanceId、Attempt 引用、HP、技能、phase、rulesVersion、loadoutSnapshot）；WalletLedger／RewardReceipt；Inventory／Equipment／PurchaseReceipt。

world、battle、economy 與 learning 的規則分開；world 觸發遭遇，learning 決定教材與作答，battle 只消費合法作答結果，economy 只消費已驗證結算。沿用 P1 的玩家固定、交易、冪等與版本檢查，不能另開 localStorage 真實進度。

位置在停止移動、互動前、場景切換與暫停時保存安全落點，不逐幀寫庫；重新開啟回最後已保存落點。跨場景與重要資料寫入失敗時保留原場景與可重試操作。未知 worldVersion／無效位置返回該地圖安全出生點並保留原始紀錄；無效 battleVersion 不重抽或假結算，保留資料後回道館說明與重開選項。

戰鬥進行中不能換裝，使用開戰時 loadoutSnapshot；兩分頁穿戴變更不回頭修改戰鬥。玩家切換與卸載取消非同步操作；舊操作完成仍只能寫原玩家。

小鎮／角色／裝備、U01 圖文音訊各有版本與完整性檢查。只有完整下載才顯示可離線；缺包可返回、下載或重試。P2 需測斷網重開後探索、戰鬥、購買、換裝與續玩，而非只測已開頁面仍有圖片。匯出／還原格式納入新增資料，完整跨裝置 gate 在 P5。

## 9. 交付與評估

規格及 task 的完整門檻見 project.md §3.3、P2-09；工程還需 P2-18 驗證地圖、入口、對話、遭遇、內容、素材與裝備引用，避免世界中有無法到達的教材。

P2 可玩性 walkthrough 由實際 reviewer 記錄：從家門找到道館、完成一戰、看懂獎勵、買裝備並看到變化、離開後恢復；可用現金流與戰鬥參數調整紀錄說明決策。P3 九名兒童另觀察迷路、誤觸、無法理解招式、只為金幣重刷、是否有自己想去的下一站；不以成人或 AI 的喜好冒充兒童結果。

P3／P4 以 encounter／story manifest 接入後續單元，可重用道館與場景；24 單元不要求 24 張地圖。新增多城鎮或更多物種須另列具體範圍與任務，不從本提案推定已授權無限制擴圖。
