# P5-04 完整備份與還原契約

2026-10-30，工程草稿。目的：家長可匯出目前所有玩家，在乾淨瀏覽器還原；同時保留既有孩子與無法歸屬的舊紀錄。實作／驗收以tasks.md P5-04為準，不因本文件存在即標完成。

- 新格式`japanese101-backup-v1`，明確DB schema 9、匯出時間、內容版本及SHA-256完整性。不是既有`journey-backup-v1`摘要；舊摘要無完整profile／設定，不能冒充可完整還原。
- 匯出固定白名單的應用資料表，包含profiles、設定、舊遊戲進度／寵物、世界位置、教學／Attempt／複習、戰鬥、錢包／ledger／purchase／裝備、模擬session／command receipt及遷移備份。只處理本機JSON，不讀任意localStorage、cookie或憑證；不把音訊圖片塞入資料備份。
- legacy `progress`／`sessions`與歷史archive仍標legacy-shared，不分配給某位孩子；本機既有legacy與archive不能被匯入檔覆蓋，衝突保留雙份的歸檔副本。
- 匯入先解析大小、格式版本、checksum、資料形狀、主鍵／ID重複、profile歸屬與必要引用。世界／內容舊版本可保存原始資料，由既有版本恢復流程處理；不能把錯誤schema當舊版本放過。
- 預覽列玩家名字、資料範圍與筆數，以及哪些現有玩家將被取代。新增玩家可直接確認；已有同ID玩家需要家長明確選取同意取代，預設不覆寫。全庫不清空，也不刪除備份未涵蓋的其他玩家。
- 預覽後若本機資料或待還原檔改變，還原拒絕並要求重新預覽。跨玩家全域ID衝突拒絕，不把其他孩子的紀錄歸給匯入玩家。
- 所有驗證在寫入前完成，替換與寫入同一交易。寫入前在交易內保存被取代的原資料archive；任何Quota／write失敗整筆回滾，原庫不變。只有commit後才顯示還原成功。
- 麥克風的瀏覽器權限不隨備份搬移；還原設定不自動授權設備權限。UI不得宣稱雲端同步或自動跨裝置。
- 還原成功重新載入目前玩家／設定；若activeProfileId不存在，選擇實際已還原玩家。沒有自動合併同名不同ID玩家。
