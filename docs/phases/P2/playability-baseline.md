# P2 可玩性審核基準（工程計算，未經人測）

產品版本 `e6444e541b710aaceaaea4807032d3904650390e`；規則 `battle-rules-v0.1`、經濟 `economy-v0.1` revision1。以下由既有純規則實際計算，沒有調整參數，不是兒童試用、真人喜好或學習成效證據。

以40HP對30HP、無裝備、每題皆答對：

| 行動順序 | 實際結果 | 真人可比較的差異 |
|---|---|---|
| 攻擊×4 | 第4回合勝利，剩24HP | 直接出招的基準；實際UI結果見final-visual/battle-result.png |
| 攻擊→夥伴技→防守→攻擊 | 第4回合勝利，剩28HP，夥伴技已用 | 第3回合強攻前防守，與純攻擊同回合數但多保4HP |
| 防守×8 | 第8回合勝利，剩22HP | 勝利先於回合上限；回合較長不代表學得更多 |

真人需另外試答錯、提示、跳過、撤退與裝備後再比較。上述「全答對」基準不能代表孩子實際操作；目前沒有真人證據能證實三招易懂或足夠有趣。

首勝60幣、重玩勝利10幣、失敗／撤退0幣；帽40、夥伴圍巾60、背包80。實際QA循環賺60、買帽後剩20。若只買帽後再存背包，仍需60幣，即6場重玩勝利；這只是目前原型的算術，不表示已核准此節奏。請記錄是否引導無意義重刷、是否能接受先逛小鎮與自由休息、下一目標是否清楚，再決定有沒有必要改版。

提早勝利的4個有效作答只累積4/5，不能當作完成五題小節。家長報告的「首次獨立答對100%、樣本4、五題小節0、練習中」已有真實UI截圖；不是已掌握或已通過JLPT。
