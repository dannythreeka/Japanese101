# 家長確認範本（不是已取得同意）

請由實際研究負責人補齊並在開始前向家長說明。未填完整或未取得家長確認，不啟動正式試用。

- 負責人與聯絡方式：待填。
- 測試日期、地點、預計時間：待填。
- 目的：了解國小兒童能否操作小鎮探索、日語教學／戰鬥、購物穿戴與續玩；不是學校考試，不保證JLPT成績或學習成效。
- 使用方式：一個匿名測試玩家；孩子可隨時暫停或退出，不需解釋，不影響任何權益。
- 必要紀錄：匿名年級組、裝置、任務是否完成、實際耗時、協助次數、問題摘要與不含姓名的作答／操作紀錄。
- 畫面錄製：預設不錄。若確實必要，需另外說明範圍並取得明確選擇；不錄臉、不錄聲音、不錄其他應用。不同意錄影仍可用人工觀察表參加。
- 資料保管人、位置、可存取者、刪除期限與撤回方式：待填。未確認前不可對外傳送資料。
- 不會把兒童姓名、聯絡資料、簽名、影像或聲音提交公開GitHub；同意文件由主持人另行保存。公開專案只放去識別的彙總與缺陷描述。

家長確認項目（實際文件由主持人保管）：理解目的與方式；同意必要匿名操作紀錄；知道孩子可停止；知道聯絡與撤回方式。錄影同意獨立選擇，不與基本參加綁定。另在開始前確認孩子本人願意參加。
