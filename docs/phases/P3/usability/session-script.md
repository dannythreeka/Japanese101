# 主持人逐步腳本（未執行）

## 測試前

1. 核對README開始條件及家長同意。詢問孩子現在是否願意玩；不願意就停止，不用獎品或分數勸留。
2. 每位使用獨立瀏覽器測試資料目錄與匿名玩家碼，禁止清空家中真實孩子紀錄。成年主持人先驗證fixture：選定已人審的教材；玩家沒有既有Attempt、技能或裝備；只提供40枚測試金幣，商店至少一件價格≤40。依實際目錄版本記錄價格，不能假設永遠不變。
3. fixture的40金幣必須標為試用補助，不作完成學習或勝利證據。紀錄配置方式、commit及錢包初始值；實作前若沒有經驗證的匯入工具，就由工程準備隔離fixture後再開始，禁止臨場改真實玩家資料。
4. 主持人只觀察，可讀出以下固定操作說明一次。後續遇到操作困難只可問「你覺得接下來可以做什麼？」一次並記為協助，不能指位置、代點或暗示答案。需要介入才能繼續則該步不算獨立成功；安全或情緒不適優先停止。

## 固定操作說明（逐字）

「這是一個可以散步的小鎮。你可以點地面移動，也可以選擇方向控制或地點清單。靠近人物或建築可以互動。道館裡可以認識日語，再用日語幫自己或夥伴出招。你可以看提示、聽聲音，也可以暫停。今天我們在測試遊戲好不好用，不是在考你；不想繼續可以隨時停下來。」

## 六個任務（依序只讀任務，不教步驟）

| 步驟 | 對孩子說 | 觀察到才記PASS |
|---|---|---|
| start | 請開始你的冒險。 | 自行到達可操作小鎮 |
| dojo | 找到可以學日語的地方。 | 自行進道館 |
| section | 認識一些日語，試著完成手帳裡的一小段練習。 | 教學與實際作答可追溯，累積5個有效首次提交；跳過／提示如實記錄，非假造正確率 |
| result | 找到剛才的結果，說說你看到什麼。 | 自行看到回饋，能指認已作答或待複習；不要求全部答對 |
| equipment | 找一件你買得起的裝備，買下並穿上。 | 實際扣款一次，持有與裝備成功，孩子可辨識穿戴改變 |
| next | 接下來你想去哪裡？試著去那裡。 | 自選一個可達目的地並走到或進入 |

每步記開始／結束時間、PASS／FAIL／STOP、協助次數、迷路／誤觸、孩子原話的匿名摘要。固定上限不是遊戲倒數；主持人若要設定session最長時間，需在所有人開始前填妥同一規則，不能為了單一結果事後延長。沒設上限就記實際時間，不自行補秒數。

另外觀察：是否理解普通攻擊／守勢／夥伴招式、答錯時是否能看懂解說、是否只為金幣重刷、是否自選探索、是否知道可以暫停。不把「喜歡」直接當作學習成效。

## 結束與重測

停止後先保存匿名觀察和隔離匯出，檢查畫面或檔案無個資再交工程。兒童不用解釋為什麼不玩。需要刪除時由實際資料保管人依同意約定處理，不能承諾已刪除而未操作。每個問題填issues.csv；工程修正有commit後，用同樣任務及協助規則另列重測，不能改成功定義。
